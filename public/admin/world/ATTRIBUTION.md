# Boundary sources

Shapes come from geoBoundaries (gbOpen), simplified for the web. Credit the sources below.
Boundaries are shown only to locate farms. They do not state any political position.

## India
- State / Union territory: CC BY 2.5 IN. Source: DataMeet India community, Election Commission of India
- District: ODbL 1.0. Source: Pathways Data Pvt. Ltd., lgdirectory.gov.in
- Sub-district / Tehsil / Block: ODbL 1.0. Source: Pathways Data Pvt. Ltd., lgdirectory.gov.in
